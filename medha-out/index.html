7-Pattern Cognitive Breakdown

Cognitive DNA Behavioral Matrix

How AdmitIQ maps your cognitive hesitation, option changes, and recall patterns:

⏱️1. Slow + Correct
Memory Fade
সময় বেশি লেগেছে (>৬ সে.) কিন্তু উত্তর সঠিক। স্মৃতি থেকে তথ্য উদ্ধারে বেগ পেতে হচ্ছে, যা পরীক্ষার চাপে ভুলে যাওয়ার ঝুঁকিপূর্ণ।
Logic: Correct = True, Time > 6s, Option Switches = 0
🐢2. Slow + Wrong
Concept Gap
অনেক সময় নিয়েও ভুল উত্তর। তাত্ত্বিক ভিত্তি দুর্বল হওয়ায় সঠিক সিদ্ধান্তে পৌঁছাতে পারেননি।
Logic: Correct = False, Time > 6s, Option Switches = 0
🔀3. Switched + Correct
Ambiguity Hesitation
অপশন একাধিকবার পরিবর্তন করে সঠিক উত্তর দিয়েছেন। নির্দিষ্ট দুটি অপশনের মাঝে সূক্ষ্ম পার্থক্য চিহ্নিত করতে দ্বিধা রয়েছে।
Logic: Correct = True, Option Switches ≥ 1
🕸️4. Switched + Wrong
Distractor Trap
অপশন পরিবর্তন করতে গিয়ে প্রশ্নকর্তার বিভ্রান্তিকর ফাঁদে পা দিয়েছেন। অপশন দুটির বৈপরীত্য পরিষ্কার করা জরুরি।
Logic: Correct = False, Option Switches ≥ 1
⚠️5. Fast + Wrong
Confidently Wrong
কোনো দ্বিধা ছাড়াই খুব দ্রুত ভুল উত্তর! এটি ভুল আত্মবিশ্বাস যা ভর্তি পরীক্ষায় মারাত্মক নেগেটিভ মার্কিং (-০.২৫) ঘটায়।
Logic: Correct = False, Time ≤ 6s, Option Switches = 0
⏳6. Skip & Return
Avoidance Blank
প্রশ্ন দেখে ভয় পেয়ে প্রথমে স্কিপ করে পরে উত্তর দিয়েছেন। তাৎক্ষণিক রিকল অক্ষমতার লক্ষণ, যা পরীক্ষার হলে আতঙ্ক বাড়ায়।
Logic: Skipped = True, Answered At End = True
⭕7. Unattempted
Uncharted Territory
প্রশ্নটির উত্তর দেওয়া হয়নি বা এড়িয়ে যাওয়া হয়েছে। এই অধ্যায়টির মৌলিক কনসেপ্টগুলো আবার রিভিশন দেওয়া প্রয়োজন।
Logic: Answer = None / Left Blank

Mastered Recall
